## 二、书写与匹配规则（改句子前必读）

1. **键** = 词序用**英文逗号**连接，与识别输出的词逐字一致（即 `CUSTOM_WORDS` / 40 词表主词）。
2. **句长 ≤ 6 词**：词队列上限 `QUEUE_LIMIT`（`script.js:52`，取自 `SENTENCE_META.queueLimit`）在 `script.js:288` 生效，超出会丢弃最早的词，长句永远凑不满。
3. **匹配方式**：`script.js:297 checkWordCombo()` 用 `队列串.endsWith(键)`（`script.js:302`），命中即出图（`script.js:304`）并**清空队列**；单词图走 `script.js:411`。
   命中后 `script.js:354 updateQueueSplitUI()` 在 WORD SEQUENCE 面板显示本表的「词序拆解」，如 `今天天气好 ＝ 今天 + 天气 + 好（003,004,005）`；
   未命中时显示当前队列的拆解与候选句（如打「我想要」→ `拆解: 我 + 想要 ｜ 候选: 我想要一杯咖啡 / 我想要一杯水`）。
4. **冲突规则**（新增/修改句子后必须重跑第三节自检）：
   - 若 A 键是 B 键的**后缀**：打 B 的过程中，队列尾部会先凑成 A → A 先命中并清空队列，B 永远出不来。
   - 若 A 键是 B 键的**前缀**：同理，A 先凑满先触发。
   - 同首词的句子（如 `等,公交车` / `等,朋友`）只要在第 1–2 个词就分叉，就不算冲突。
5. **图片名** = 句子名 + `.png`，词必须与 `dataset/词汇编号表.txt` 的主词逐字一致（020 → `组词效果/和.png`）；
   不要再用冒号拼别名（旧的 `组词效果/一起:和.png` 已按主词改名为 `和.png`）。
6. **疑问句不写疑问词**：「吗 / 呢 / 句末的不」在手语里靠**表情（扬眉、身体前倾）**表达，不进键。
   - 例：`你吃了吗` = 你 + 吃 + 了 → 键 `你,吃,了`（**不是** `你,吃,了,不`）。
   - 「句子」列与图片名可保留「吗」用于显示，但键里绝不出现。
   - `不`(017) 只作**否定词**用（如 `我,不,喜欢,苹果`），不再兼作疑问标记。
7. **改完必须重新生成**：`python3 tools/build_sentences.py`（只校验不写文件用 `--check`）。
   脚本会检查：键唯一、词都在 `词汇编号表.txt`、四列自洽、句长 ≤ 6、无前缀/后缀冲突、键里无疑问词；
   **任一条不过就报错退出且不写 `sentences.js`**，所以生成出来的文件一定是干净的。
